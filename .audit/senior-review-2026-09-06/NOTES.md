# Senior app review — play-through notes (2026-09-06, running log)

Method: prod PWA in the browser at 375×812 (console + network readable) cross-checked natively in the iPhone 17 Pro simulator.
Findings are logged as found; the written review is assembled at the end.

## Found so far
- WEB SHELL: the tab strip (Play · Daily · Online · Profile · gear) stays visible and tappable DURING a quiz on the web, so a player can leave a live quiz with no confirm (the native app hides the tab bar in-game). Also its "Daily" label lagged the app's "History" (fixed: BiqNav.jsx) and it carries a second ball mark + a second gear above Home's own header.
- RESULTS (Daily 7): emoji glyphs remain — "+40 XP earned ⚡", "🔥 Best streak: 4 in a row"; the "FINAL SCORE" count-up showed "1" while the caption said 4/7 — confirmed to be rAF throttling in a hidden tab (finished at 4 once fronted); not a bug.
- QUIZ: the question card's fade-in shows grey text briefly (q-fade) — check whether the transition is too slow on device.
- Difficulty sheet stayed open when a shell tab was tapped underneath it (web) — moot now the sheet is gone, but the pattern (sheets not closed on tab change) may exist for other sheets.
- The old Classic "Ready?" gate covered the header with no back — fixed today (no gate at all).
- Profile card printed "64 · Silver" after one Footle — fixed today.
- QUIZ (web, 375×812): after the last answer the sticky "Results →" button floats OVER the "Why?" explanation box — the last explanation of a round is half-hidden under the primary button. Same sticky pattern for "Next →" on long questions: check native at Q with a long explanation.
- QUIZ: the Daily 7 answer reveal is good craft (✓/✗ tiles, "Why?" box, Report a problem) — keep; but "✓ Correct!" / "✗ Incorrect" banners use text glyphs where the option tiles already use drawn icons.
- RESULTS (non-daily, web): FIVE stacked actions in THREE styles (green filled "Play today's Footle", ghost "Play Again", two green-OUTLINE "Share Score"/"Stump a mate", underlined "Back to Home") + "+10 XP earned ⚡". The wall-of-options the critique flagged on Home, on the results screen. One primary, one secondary, the rest as text. The missed-answers review below it is best-in-class (explanation + "This looks wrong") — keep.
- RESULTS (non-daily): no return-loop panel by design (non-daily) — but a non-daily finisher who has NOT played today's dailies gets only "Play today's Footle"; the panel's "Still open today" rows would do the same job in the app's one anatomy.
- SETTINGS: "Show Hints — First-letter hints on typed questions (Easy mode)" — the bank has had ZERO typed questions since 2026-05-07 (df54c40); a live toggle for a feature that does not exist. "Timer — … in Standard and Speed modes" — no mode is called Standard; Speed Round is not on Home. "Sign up to unlock leaderboards and online play" — there is no leaderboard (deferred). Three promises Settings cannot keep; same class as the retired difficulty copy, ungated.
- SETTINGS: ABOUT shows "v1.1.0" — check against package.json / the store build.
- PROFILE (web guest, after ONE Classic round with 1/10): the card prints "57 · BRONZE" with six league ratings 49–71 and "Strongest: Serie A · 71". One correct answer, six confident numbers — the prior leaking through the tier model. The honest fix from today (needs answered questions) is a floor; the model still fabricates precision from n=1.
- ONLINE / JOIN: typing a garbage code (ZZZZZZ) and tapping Join opens "Join the game — Your friend's invite code ZZZZZZ is ready. We'll drop you straight into the room as soon as you're signed in." The code is never checked before the promise; a typo only fails AFTER the sign-up / guest step. Validate the room (one cheap RPC) before the modal; say "No room with that code" inline.
- ONLINE / JOIN modal: "⚡ Play as guest" — emoji in a primary button; and it is a centred box while the rest of the app moved to bottom sheets.
- SETTINGS / ABOUT: `APP_VERSION = "1.1.0"` hardcoded in App.jsx (web fallback) while the store builds are 1.7.x — stale on every web visit.
- ONLINE guest pitch: live on prod and reads well at 375; the three step chips wrap to two lines at this width even with the short labels — consider a single row of text ("Create a room → share the link → answer live").
- BUG — PENDING JOIN RE-PROMPTS OVER A LIVE QUIZ: after "Not now" was never tapped, a full reload + starting the Arsenal club quiz showed the "Join the game" modal AGAIN, over the running quiz (timer at 13s underneath). The pending code is persisted and re-armed on every load regardless of screen. It must (a) never open while inGame, (b) expire, (c) be validated first.
  · Storage: `biq_pending_join = {"c":"ZZZZZZ","at":<ms>}` (useAuth.jsx keeps it across sign-out); "Not now" clears it. The prompt is re-armed on every boot while the key exists — no inGame guard, no expiry check surfaced, no validation.
