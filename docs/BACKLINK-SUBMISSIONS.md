# Backlink submissions — the working list

Every URL below was checked live on **2026-07-30**. Nothing here is a guess.

Two rules, both learned the hard way:

- **Always brand it "Footle by Ball IQ".** Three other products own the bare
  name "Footle"; an unbranded listing sends traffic to a competitor.
- **Always link the playable no-login game**, never the App Store. The measured
  finding is that playable pages hold attention (109–145s) and lists without a
  taster got 2.3s.
