# Data study — draft #1

**Task #64.** The asset exists to attack our one measured ceiling: authority.
We have roughly zero external links, and every on-page fix from 2026-07-28 sits
underneath that. Football media links to **data**, not to quizzes. This is the
only data nobody else has.

Generated by `scripts/bank-insights.mjs` — re-run it before publishing, the
bank changes weekly.

---

## The finding that survives scrutiny

**Football trivia has a memory that starts in 1990.**

Questions in our bank that reference a year, by decade:

| Decade | Questions |
|---|---|
| 1900s–1940s | 424 combined |
| 1950s | 219 |
| 1960s | 355 |
| 1970s | 430 |
| 1980s | 437 |
| **1990s** | **805** |
| **2000s** | **966** |
| **2010s** | **1,359** ← peak |
| 2020s | 1,034 |

The 2010s alone carry more than the entire pre-1950 era by a factor of three.
Half a century of football — the era of Matthews, Puskás, the Busby Babes —
occupies less space in the collective quiz memory than one recent decade.

**Why this is publishable:** it is not an artefact of what we chose to cover.
It is a property of how football is *written about* and therefore how it is
remembered. It gives a football desk a headline they can argue with, which is
exactly what earns a link.

## ⚠️ The finding that does NOT survive scrutiny — do not lead with it

The "most-asked-about" table (Real Madrid 343, Manchester United 195, Bayern
Munich 147) is **partly self-inflicted**. We ship 61 club packs, so a club with
a pack is mentioned more by construction. It measures what OUR BANK is about,
not what football trivia is about.

If used at all it must be framed as *"across our own 5,834 questions"*, never
as a claim about the sport. A journalist who checks will notice, and being
caught overstating once costs more than the link is worth.

Two mechanical caveats if it is used: "Man City" (53) and "Manchester City"
(91) count separately, and possessives were folded but aliases were not.

## The angle we cannot write yet

**"The 20 hardest questions in football, ranked by how often people get them
wrong."** This is the strongest version — it is genuinely novel, inherently
shareable, and impossible to copy.

We cannot write it because we do not collect per-question answer rates. Note
the measurement trap from the question-bank skill: `scores` records
survival/daily/classic/wc2026/chaos/legends only — **Footle, Club Quiz and
League Quiz write nothing to it.**

**Alex's decision:** start collecting per-question answer rates? It unlocks
this piece and would also let us grade difficulty by evidence rather than
editorial judgement — which would make the difficulty-honesty work (#40)
self-correcting.

## Supporting material we already own

- **5,834 questions**, of which **4,394 (75.3%)** carry a written explanation
  — deliberately not all; some answers need none
- **A documented three-stage forge**: generate → examiner → skeptic, with only
  survivors committed
- **A distractor audit that found a 45% defect rate** in the sample reviewed
- **329 corrections applied in a single day** (2026-07-28)
- Difficulty mix: 1,476 easy / 2,858 medium / 1,500 hard

That last set is the credibility paragraph. It is also the part currently
invisible to readers everywhere except the editorial strip added in 5e9a3ec.
